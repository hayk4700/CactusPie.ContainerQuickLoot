# CactusPie.ContainerQuickLoot

**Лут сразу попадает в помеченные контейнеры — без лишнего перетаскивания.**

Клиентский плагин для **SPT 4.1.5** (Single Player Tushonka).

[English](README.md) · [Русский](readme_rus.md)

---

## Описание

**Ctrl+click** по предмету лута переносит его в подходящий контейнер с тегом `@loot`.

Пример: пометьте кейс для документов тегом `@loot` и положите его в защищённый контейнер. Ключи, которые вы забираете через Ctrl+click, окажутся в этом кейсе автоматически.

То же самое работает для **лута с земли**: предметы с пола, полок и других мест.

> Работает **только в рейде**. В схроне убежища плагин не действует.

**Плагин:** `CactusPie.ContainerQuickLoot`  
**Версия:** 1.9.0 · **SPT:** 4.1.5 · **Тип:** клиентский плагин (BepInEx)

---

## Возможности

- Автоматический перенос предметов по Ctrl+click в помеченные контейнеры
- Автоматический перенос лута, поднятого с земли
- Опциональное слияние стаков (патроны, деньги и похожие предметы)
- Числовые суффиксы `@loot` для приоритета контейнеров
- Своё ключевое слово тега в меню F12

## Установка

1. Скачайте `CactusPie.ContainerQuickLoot.dll`.
2. Скопируйте файл в папку SPT:

```
BepInEx\plugins
```

3. Запустите SPT. Откройте меню **F12** и найдите секцию **Container quick loot setting (CQLv4)**.

---

## Как пользоваться

1. Положите контейнер в инвентарь (например, кейс для документов).
2. Нажмите по контейнеру правой кнопкой и выберите **Tag**.
3. Укажите тег `@loot`.
4. В рейде сделайте **Ctrl+click** по подходящему предмету (например, ключу) или поднимите лут с земли.
5. Предмет автоматически попадёт в этот контейнер.

Уберите тег `@loot`, чтобы контейнер перестал быть целью для автолута.

---

## Приоритет тегов

Добавьте число после `@loot`, чтобы выбрать, какой контейнер заполняется первым. **Меньшее** число — выше приоритет. Без суффикса считается `0`.

| Тег | Приоритет |
|---|---|
| `@loot` | 0 (самый высокий) |
| `@loot1` | 1 |
| `@loot2` | 2 |
| `@loot10` | 10 |
| `@loot20` | 20 |

Примеры:

- `@loot` используется раньше, чем `@loot1`
- `@loot10` используется раньше, чем `@loot20`
- Если у двух контейнеров одинаковый тег, игра сама выберет один из них

## Настройки (F12)

Секция: **Container quick loot setting (CQLv4)**

| Настройка | По умолчанию | Что делает |
|---|---|---|
| Enable for Ctrl+click | Вкл. | Переносить предметы в помеченные контейнеры при Ctrl+click в меню лута |
| Enable for loose loot | Вкл. | Переносить предметы, поднятые в мире, в помеченные контейнеры |
| Merge stacks | Вкл. | Склеивать стаки (деньги, патроны и т.п.) при переносе в контейнер с тегом |
| Merge stacks for non-loot containers | Вкл. | Склеивать стаки и при переносе в контейнеры **без** лут-тега |
| Customize the keyword used to denote loot containers in tags | `@loot` | Сменить ключевое слово тега, если не хотите использовать `@loot` |

## Сборка из исходников

Нужны SDK **.NET Framework 4.7.2** и установленный **SPT 4.1.5**.

1. Клонируйте репозиторий.
2. Скопируйте эти сборки в `CactusPie.ContainerQuickLoot\libs` (из папки `Managed` клиента SPT и `spt-reflection.dll` из `BepInEx\plugins\spt`):

   - `Assembly-CSharp.dll`
   - `Comfort.dll`
   - `Comfort.Unity.dll`
   - `ItemComponent.Types.dll`
   - `UnityEngine.dll`
   - `UnityEngine.CoreModule.dll`
   - `UnityEngine.InputLegacyModule.dll`
   - `spt-reflection.dll`

3. Перед копированием `Assembly-CSharp.dll` один раз запустите SPT до главного меню, чтобы клиентские сборки были готовы.
4. Соберите проект:

```bash
dotnet build CactusPie.ContainerQuickLoot/CactusPie.ContainerQuickLoot.csproj -c Release
```

Готовый DLL появится в `CactusPie.ContainerQuickLoot\bin\Release\net472\`.
